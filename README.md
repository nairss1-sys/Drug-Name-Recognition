Handwritten Drug Name Samples

This directory contains sample handwritten drug name images used for training and evaluating the Gen-HDR-GAN handwritten drug name recognition and synthesis framework.

Contents

Each image depicts a single handwritten instance of a drug name, contributed by different writers to capture variation in stroke style, slant, spacing, and legibility. Samples are grouped by drug name and indexed with a unique numeric ID.

Drug Name	Sample ID Range	Example Count
Aceta	9	1
Alatrol	90–99	10
Diflu	893–905	13

Note: ID ranges are non-contiguous across drug names because sample IDs are assigned globally across the full dataset, not per-class.
